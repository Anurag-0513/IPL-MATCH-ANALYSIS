# IPL Match Analysis Using Python (2024-2026)

## 1. Introduction
This is a beginner-level Python project that analyses IPL season information for 2024, 2025 and 2026. The data is organised in CSV files and read using Python's built-in `csv` module.

## 2. Objectives
- Display the winner and runner-up of each season.
- Display Orange Cap and Purple Cap information.
- Display playoff scorecards, venues, winners and Player of the Match.
- Display top five run scorers, wicket takers and six hitters.
- Compare the total number of boundaries across seasons.

## 3. Software Requirements
- Python 3.10 or later (Python 3.14 should also work)
- IDLE, VS Code or any Python editor
- No external Python packages are required.

## 4. Project Folder Structure
IPL_Match_Analysis_Project/
- ipl_match_analysis.py
- data/
  - season_summary.csv
  - playoff_results.csv
  - top_performers.csv
- sample_output.txt
- project_report.txt
- README.txt

## 5. How to Run
1. Extract the ZIP file.
2. Open the extracted `IPL_Match_Analysis_Project` folder in VS Code.
3. Open a terminal in that folder.
4. Run: `python ipl_match_analysis.py`
5. Select an option from the menu.
6. Keep the `data` folder in the same main project folder as the Python file.

## 6. Python Concepts Used
- Variables: store user choices and data.
- Lists: store rows read from CSV files.
- Dictionaries: access each CSV row using column names.
- Functions: divide the program into small tasks.
- `for` loop: read and display records.
- `if-elif-else`: select menu options and categories.
- `while` loop: keep the menu running until Exit is selected.
- CSV file handling: read the project data.

## 7. Expected Result
The program shows a menu. The user can select a season summary, playoff results, top five players or boundary comparison. The program displays the selected information in the terminal.

## 8. Data Source and Note
The supplied file `IPL Match Analysis (2024–2026).pdf` is the source for the values in these CSV files. The project reproduces the supplied document's data; it does not independently verify the cricket statistics.

## 9. Conclusion
This project demonstrates how basic Python programming can be used to read, organise, compare and display sports statistics from CSV files.
